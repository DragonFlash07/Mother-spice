# Mother's Spice 🌿🥭

Founder: Parthiv Shah. Streamlit catalogue, family story, India–Australia mango community, enquiry form and WhatsApp links.

## Local

```powershell
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Push the project to GitHub `DragonFlash07/Mothers-Spice` and connect it to Streamlit Community Cloud, selecting `app.py` on the main branch. Subsequent GitHub commits redeploy the app.

## Important

The enquiry form prepares WhatsApp/email messages. It does not save submissions or send them automatically. There are no live orders or payments. Confirm food safety, labelling, allergens, price, stock, consent and business compliance before launch.
